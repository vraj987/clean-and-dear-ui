# Simple BytePe Storefront UI

## What I’ll build
- Replace the blank page with a single, polished BytePe-style storefront at `/`.
- Add the circular BytePe logo, search, compact navigation, and a scrollable category row.
- Create one strong promotional banner with phone imagery and a clear shop action.
- Add a few concise product sections using reusable product cards, prices, discounts, and monthly payment labels.
- Finish with a small benefits strip, partner names, and a simple footer.

## Interaction
- Search filters the visible sample products.
- Category buttons switch the highlighted category and filter products.
- Navigation and product actions remain front-end-only; no accounts, checkout, payments, or saved data.
- Mobile navigation opens from a menu button.

## Visual direction
- Follow the uploaded brief: orange-red actions, white and pale-gray surfaces, black typography, serif section headings, and sans-serif utility text.
- Keep the page substantially shorter and simpler than the full reference specification.
- Use clean product illustrations built from styled UI shapes so the page remains lightweight and self-contained.

## Technical details
- Define all colors, typography, radii, and shadows as semantic tokens in the global design system.
- Implement the page in the existing TanStack Start home route with accessible React controls and Lucide icons.
- Add complete page-specific title and social metadata.
- Verify compilation and desktop/mobile rendering after implementation.
